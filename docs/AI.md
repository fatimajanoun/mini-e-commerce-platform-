# AI Documentation

I used AI as a development assistant to reduce development time and help me throughout different parts of the project.

I mainly used it for:

- Frontend implementation and UI development.
- Debugging and identifying issues in my code.
- Refactoring and improving existing code.
- Writing GitHub commit messages and descriptions.
- Reviewing different implementation approaches and edge cases.
- Helping me write and review tests.

I reviewed and tested all AI-generated suggestions and code before using them. I also adapted the suggestions to fit my project and made the final implementation and technical decisions myself.
